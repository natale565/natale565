### What I'm Building

**🎮 [Twitch Dashboard Tracker](https://github.com/natale565/twitch-dashboard-tracker)**
Backend-heavy analytics dashboard for streamers. JWT authentication with bcrypt-hashed credentials, protected route middleware, and a PostgreSQL layer using connection pooling. Full CRUD across user and stream data, with a scheduled snapshot-and-diff job for tracking follower changes over time.
`Node.js` `Express` `PostgreSQL` `JWT`

**💾 [Yourspace](https://github.com/natale565)** <!-- update this link to the real repo -->
A MySpace-inspired social network — profile customization, the whole nostalgia trip. Built on Next.js App Router with TypeScript, Supabase auth, and row-level security policies enforcing per-user data access. Server-side session handling via middleware-managed cookies.
`Next.js` `TypeScript` `Supabase` `Chakra UI`
